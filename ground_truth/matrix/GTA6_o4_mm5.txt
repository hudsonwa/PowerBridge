{ ============================================================================
  GTA6 - comprehensive FULLY-GROUNDED ground-truth strategy  (MultiCharts PowerLanguage)
  ----------------------------------------------------------------------------
  TYPE:  SIGNAL  (PowerLanguage Editor -> New -> Signal)

  WHAT IT DOES
    The "no stone unturned" calculation / statistics / data-introspection coverage
    script. SINGLE-DATA (no Data2 - multi-data is covered by GTA5). It EXERCISES every
    transpilable PowerLanguage keyword that GT1-GT4 / GT_master / GTA5 do NOT already
    use, other than the deliberate exclusions, so the transpiler gains coverage for:
      - the array / list family (Array_*, Fill_Array, SumList/AvgList/MaxList2/MinList2)
      - the full date/time conversion family (Encode/Format/StringTo*, EL<->DateTime,
        Time*_s, DayOfWeekFromDateTime, MillisecondsFromDateTime, IncMonth, *ToString)
      - the session-family remainder (Sess1/2*, SessionCount(MS), SessionStart/EndDay(MS),
        SessionStart/EndTimeMS, SessionEndTime, SessionLastBar)
      - bar / data metadata (CurrentBar, Current/BaseDataNumber, BarStatus, BarType(_ex),
        IntervalType(_ex), MaxBarsBack/Forward, LastCalc DateTime/JDate/MMTime/MSTime/
        SSTime, TickID, Trade Volume/Date/Time)
      - strategy performance stats (NumWin/Los/EvenTrades, Largest*, PercentProfit,
        MaxConsec*, AvgBars*/TotalBars*, MaxContract/Position Profit/Loss, MaxContracts,
        MaxShares(Held), MaxEntries, MaxPositionsAgo)
      - open-position + closed-trade introspection (OpenEntry*, PosTrade*)
      - entry/exit metadata (Entry/Exit Name/Date/Time/DateTime, CurrentEntries/Shares,
        ExecOffset)
      - order types + money-management forms (limit/stop/on-close/from-entry, BuyToCover,
        SetStopLoss/_pt, SetProfitTarget/_pt, SetBreakEven/_pt, SetPercentTrailing/_pt,
        SetDollarTrailing, SetTrailingStop_pt, SetStop Contract/Share/Position,
        SetExitOnClose) - referenced in OrderMode/MMVariant-gated branches for compile
        coverage (need not all execute in one capture)
      - misc (AlertEnabled, Abort, CommandLine, Description, Category, Symbol(Name),
        SymbolCurrencyCode, ExpirationDate)
    Appends one comma-delimited row per bar to TWO files (column-limit safety):
      OutPath  = calc / data / array / date-time / session / bar-metadata columns
      OutPath2 = stats / trade-introspection / entry-exit columns

  TRADES
    A simple always-evaluated FastMA-crosses-SlowMA entry fires at market on every
    cross (Buy on cross-up, SellShort on cross-down) so the trade-statistic and
    trade-introspection reserved words hold real non-zero values. SetExitOnClose.

  ORDER MODES  (only the ORDER block is gated by OrderMode; the calc + stats battery
  runs every bar). Run the calc capture with OrderMode=0 (market reversal). The other
  modes parse/compile and are coverage-counted:
    0 = MA-cross reversal at market  (default; this is the TRADING run)
    1 = limit entries          2 = stop entries
    3 = this-bar-on-close       4 = named exits from entry + BuyToCover short exit

  MM VARIANTS  (only the MM block is gated by MMVariant). 0 = none (default calc run);
  1..10 isolate one stop family per run (same matrix as GTA5).

  STYLE (KISS)
    - One value per line; CSV rows are flat concatenations, no nesting.
    - Single-level conditionals only (gate with compound `and`).
    - Assignment AND equality are '='  (never ':=', never '==').
    - Header + row built INCREMENTALLY across many statements (string-limit safety).

  GROUNDING
    Every used-but-undeclared keyword/function is proven by
      python tools/mc_ground_check.py ground_truth/GTA6_strategy.txt
    against the PowerLanguage Keyword Reference alphabetical INDEX + a body Usage
    entry. Per-token citations: ground_truth/GTA6_GROUNDING.md.

  RUN
    SINGLE data series (NQ-like 1-min). Bar Magnifier OFF, IOG OFF, single session.
    1 contract base, commission = 0, slippage = 0. Delete BOTH OutPath files first
    (Print(File()) appends). See ground_truth/GTA6_RUNSHEET.md.
============================================================================ }
