{ ============================================================================
  GTA5 - comprehensive FULLY-GROUNDED ground-truth strategy  (MultiCharts PowerLanguage)
  ----------------------------------------------------------------------------
  TYPE:  SIGNAL  (PowerLanguage Editor -> New -> Signal)

  WHAT IT DOES
    The most comprehensive single-strategy language-surface capture in this repo.
    Extends GT_master with: multi-data accessors (Data2), session/time functions,
    all five order fill modes (incl. reversal + a 2-contract entry with FIFO
    partial close + explicit named exits from entry), the full money-management
    stop matrix in BOTH dollar and point (_pt) forms, the "stub" performance
    columns (ExitPrice/BarsSinceExit/PositionProfit/GrossProfit/GrossLoss/
    MaxContractsHeld/MaxIDDrawDown/AvgEntryPrice), a calculation battery
    (pivots/swings, daily accessors, NthMax/MinList, DateTime decomposition,
    contract spec, PercentChange/PercentR, ParabolicSAR/KeltnerChannel/AccumDist),
    and per-bar DEFERRED-INDICATOR DIAGNOSTICS (raw windowed sums for Correlation,
    raw HH/LL/%K + Smooth/Slow for Stochastic) so the exact MC formula is derivable.
    Appends one comma-delimited row per bar (INCLUDING OHLCV) for validation.

  ORDER MODES  (a single strategy cannot fire market + limit + stop + on-close +
  exits at once without conflicts, so ONLY the order block is gated by OrderMode;
  the calc battery + diagnostics run every bar). Run once per mode, changing OutPath:
    0 = MA-cross REVERSAL, next bar at market  (Buy reverses short / SellShort
        reverses long) PLUS a 2-contract long entry + a 1-contract partial Sell
        to exercise FIFO partial close.                                  (default)
    1 = limit entries        (deterministic price: Low buy-limit, High short-limit)
    2 = stop entries         (deterministic price: High buy-stop, Low short-stop)
    3 = this-bar-on-close entries
    4 = explicit NAMED exits with stop / limit prices using `from entry("label")`

  MM VARIANTS  (isolate one stop family per run so the capture tells you which
  fired). ONLY the MM block is gated by MMVariant; set it per run:
    0 = none
    1 = SetStopLoss(dollar)        2 = SetStopLoss_pt(point)
    3 = SetProfitTarget(dollar)    4 = SetProfitTarget_pt(point)
    5 = SetBreakEven(dollar)       6 = SetBreakEven_pt(point)
    7 = SetPercentTrailing(dollar) 8 = SetPercentTrailing_pt(point)
    9 = SetDollarTrailing(dollar) 10 = SetTrailingStop_pt(point)
  (The basis switch SetStopContract / SetStopShare / SetStopPosition is selected
   by StopBasis and applied in every non-zero MM variant.)

  STYLE (KISS)
    - One value per line; CSV row is a single flat concatenation, no nesting.
    - Single-level conditionals only; order syntax is fixed word order.
    - Assignment is '='  (never ':=').  Gated blocks use compound `and` conditions.

  GROUNDING
    Every keyword, function, operator and bracket is grounded in the official
    PowerLanguage Keyword Reference (the PowerLanguage keyword reference) and/or the
    TradeStation EL reference (the TradeStation EL reference); see
    ground_truth/GTA5_GROUNDING.md for the per-token citation table.

  RUN
    Requires a 2-data-stream chart (Data1 = primary, Data2 = second symbol/series)
    for the multi-data columns. 1 contract base, commission = 0, slippage = 0,
    bar magnifier OFF. Delete the target OutPath file first (Print(File()) appends).
    Reload once to capture. See ground_truth/GTA5_RUNSHEET.md for the exact matrix.
============================================================================ }

{ ---- single-level If / Then / Else ---- }
If close > open Then IfElseOut = 1 ;
Else IfElseOut = -1 ;

{ ---- indicators / signals ---- }
FastMA = average(close, FastLen) ;
SlowMA = average(close, SlowLen) ;
AvgC = average(close, Len) ;
AtrC = avgtruerange(Len) ;
GoLong = FastMA crosses above SlowMA ;
GoShort = FastMA crosses below SlowMA ;

{ ---- deterministic order prices ---- }
LimitBuyPx = low ;
StopBuyPx = high ;
LimitShortPx = high ;
StopShortPx = low ;

{ ============================================================================
  MULTI-DATA ACCESSORS  (Data2 required on the chart)
============================================================================ }
D2Close = close of Data2 ;
D2C = close of Data2 ;
D2H = high of Data2 ;
D2L = low of Data2 ;
D2CN = close of Data2 ;

  SESSION / TIME
============================================================================ }

SessEnd = SessionEndTime(1, 1) ;

BarIntv = BarInterval ;
CalcD = calcdate(date, -14) ;
CalcT = calctime(time, -15) ;
Dow = DayOfWeek(date) ;

{ TimeToMinutes(Time) inlined: Time is HHmm -> minutes since midnight
  = HH*60 + mm, where HH = IntPortion(Time/100), mm = Time - HH*100 }
MinFromMid = IntPortion(time / 100) * 60 + (time - IntPortion(time / 100) * 100) ;

{ MinutesToTime(MinFromMid) inlined: minutes -> HHmm
  = HH*100 + mm, where HH = IntPortion(min/60), mm = min - HH*60 }
TimeBack = IntPortion(MinFromMid / 60) * 100 + (MinFromMid - IntPortion(MinFromMid / 60) * 60) ;

{ ============================================================================
  CALC BATTERY  (runs EVERY bar regardless of OrderMode / MMVariant)
============================================================================ }
{ ---- pivot / swing family DROPPED: PivotHighVS/PivotLowVS(+Bar) and
  SwingHigh/SwingLow(+Bar) have NO keyword-reference entry in the PowerLanguage keyword reference

{ ---- daily / secondary accessors ---- }
DOpen = dailyopen ;

DLow = dailylow ;
DClose = dailyclose ;
OpD0 = opend(0) ;

LoD0 = lowd(0) ;

{ Yesterday inlined: it is a TS-EL word MC does NOT implement (throws a syntax
  error); the prior trading day's close is CloseD(1). See lessons.md / GROUNDING. }
Yest = closed(1) ;
PrevC = prevclose ;

{ ---- variadic NthMaxList / NthMinList ---- }
NthMax = NthMaxList(2, open, high, low, close) ;
NthMin = NthMinList(2, open, high, low, close) ;

{ ---- DateTime decomposition (argument = the DateTime reserved word) ---- }
DfDt = DayFromDateTime(datetime) ;

{ ---- contract specification ---- }

{ ---- percent functions (inlined from proven primitives) ---- }
{ PercentChange(Close, Len) = ((Close - Close[Len]) / Close[Len]) * 100 }
PctChg = iff(close[Len] <> 0, (close - close[Len]) / close[Len] * 100, 0) ;

{ PercentR(Len) = Williams %R = (HH - Close)/(HH - LL) * 100 over Len bars
  HhPr = Highest(High,Len), LlPr = Lowest(Low,Len) (vars below) }
HhPr = highest(high, Len) ;
LlPr = lowest(low, Len) ;
PctR = iff(HhPr - LlPr <> 0, (HhPr - close) / (HhPr - LlPr) * 100, 0) ;

{ ---- ParabolicSAR DROPPED: no keyword-reference entry in the PowerLanguage keyword reference
  (zero mentions); var-parameter multi-output, not cleanly inlineable.
  See GTA5_GROUNDING.md "Dropped". }
{ ---- Keltner channel inlined: Average(Close,Len) +/- NumATRs * AvgTrueRange(Len) ---- }
KcMid = average(close, Len) ;
KcAtr = avgtruerange(Len) ;
KcUp = KcMid + 1.5 * KcAtr ;
KcDn = KcMid - 1.5 * KcAtr ;

{ ---- AccumDist inlined as cumulative money-flow:
  per-bar ((Close-Low)-(High-Close))/(High-Low)*Volume, summed cross-bar ---- }
If high - low <> 0 Then AdV = AdV + (close - low - (high - close)) / (high - low) * volume ;

{ ============================================================================
  DEFERRED-INDICATOR DIAGNOSTICS  (emit RAW inputs so MC's formula is derivable)
  Per reviews/DEFERRED_INDICATORS.md: do NOT fabricate formulas - just emit
  MC's value alongside the windowed raw inputs / intermediates.
============================================================================ }
{ ---- Correlation(Close, Open, CorrLen): MC value + windowed sums ---- }
CorrMC = correlation(close, open, CorrLen) ;
SumX = 0 ;
SumY = 0 ;
SumXY = 0 ;
SumX2 = 0 ;
SumY2 = 0 ;
NObs = CorrLen ;
For Idx = 0 to CorrLen - 1 Begin
	Xv = close[Idx] ;
	Yv = open[Idx] ;
	SumX = SumX + Xv ;
	SumY = SumY + Yv ;
	SumXY = SumXY + Xv * Yv ;
	SumX2 = SumX2 + Xv * Xv ;
	SumY2 = SumY2 + Yv * Yv ;
End ;

{ ---- Stochastic: MC %K/%D + raw HH/LL/raw%K ---- }
StochRet = Stochastic(high, low, close, StochLen, StochLen1, StochLen2, 1, oFastK, oFastD, oSlowK,
	oSlowD) ;
HH = highest(high, StochLen) ;
LL = lowest(low, StochLen) ;
RawK = 0 ;
If HH - LL > 0 Then RawK = (close - LL) / (HH - LL) * 100 ;

{ ============================================================================
  ORDER BLOCK  (gated by OrderMode; single-level compound conditions)
============================================================================ }
OrderTag = "" ;

If OrderMode = 0 and GoLong and MarketPosition <= 0 Then Begin
	Buy ( "LE_MKT" ) 2 contracts next bar at market ;
	OrderTag = "LE_MKT" ;

	SellShort ( "SE_MKT" ) 1 contract next bar at market ;
	OrderTag = "SE_MKT" ;

	Buy ( "LE_LMT" ) 1 contract next bar at LimitBuyPx limit ;

	SellShort ( "SE_LMT" ) 1 contract next bar at LimitShortPx limit ;
	OrderTag = "SE_LMT" ;
End ;

	Buy ( "LE_STP" ) 1 contract next bar at StopBuyPx stop ;
	OrderTag = "LE_STP" ;

If OrderMode = 2 and GoShort and MarketPosition >= 0 Then Begin
	SellShort ( "SE_STP" ) 1 contract next bar at StopShortPx stop ;
	OrderTag = "SE_STP" ;

	Buy ( "LE_CLS" ) 1 contract this bar on close ;
	OrderTag = "LE_CLS" ;

	SellShort ( "SE_CLS" ) 1 contract this bar on close ;

	Buy ( "LE4" ) 1 contract next bar at market ;
